## Run the assembler

From this directory:

```bash
python assembler.py Box.asm
```

This creates `Box.hack`. To choose an output filename:

```bash
python assembler.py Box.asm output.hack
```

The assembler strips comments and blank lines, records labels in pass one, and translates instructions in pass two. New variables are allocated from RAM[16]. For K=80, duplicate label declarations produce a warning; the first definition is retained.

## Box calculations

- Starting row: 80
- Height: 20 rows (80 through 99)
- Width: `16 * ((80 % 4) + 1) = 16` pixels
- Words per row: 1
- First screen word: `16384 + 32*80 = 18944`
- Next row: add 32 to the screen address

The program checks `KBD` continuously. A nonzero keyboard value draws `-1` to the target word in each of 20 rows. A zero value writes `0` to those same words.
